# Battesimo di Megan

Invito digitale per il Santo Battesimo di Megan: busta con sigillo da aprire, ghirlanda di roselline e nebbiolina, conto alla rovescia, programma della giornata, "Salva la data" e conferma della presenza via WhatsApp.

## Avvio in locale

Serve [Node.js](https://nodejs.org/).

```bash
node serve.js
```

Poi apri http://localhost:3456

## Modificare i dati dell'evento

Data, orari, luoghi e numero WhatsApp per le conferme sono nel blocco `EVENTO` in cima allo script di [BATTESIMO/index.html](BATTESIMO/index.html). La data e l'ora sono sempre in ora italiana.
